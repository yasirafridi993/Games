# CAR RACING

A complete 3D arcade racing game for **Windows PC**, written in **Python + Panda3D**.
Choose a car and one of eight distinct circuits, configure a race against 1–7 AI drivers,
choose a difficulty and lap count, then race
with a rolling start, checkpoints, shadows, engine/tire/crash sounds and background music.

Everything (car, track, scenery, sounds, music) is generated by code, so the game runs
without downloading any extra assets.

## Requirements

* Windows 10 / 11 (64-bit)
* Python **3.9 or newer** (64-bit). Python 3.13 needs Panda3D 1.10.15+, which `pip` picks automatically
* A GPU with OpenGL 3.x support (any normal desktop or laptop from the last ~10 years)
* One dependency: `panda3d` (see `requirements.txt`)

## Installation

```bash
# 1. open a terminal (PowerShell or cmd) in the CarRacing folder
cd CarRacing

# 2. (recommended) create a virtual environment
python -m venv .venv
.venv\Scripts\activate

# 3. install the dependency
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

The first start generates the sound files into `assets/sounds/` (about a second).

## How the race works

* Race Setup leads through the Garage, Track Select and race configuration screens.
  Choose among seven performance-differentiated car types and eight distinct circuits:
  Harbor City Circuit, Mountain Pass, Sirocco Rally, Blackpine Forest, Azure Coast Highway,
  Foundry Loop, Neon Afterdark and Razorback Extreme.
* Tracks have independent spline layouts, widths, metadata, racing lines, and authored
  elevation profiles. The city, desert, forest, coast, industrial, neon and mountain
  environments use different terrain palettes, scenery and atmosphere. Mountain grades
  are rendered on the road while the existing arcade collision/lap simulation remains 2D.
  Track difficulty is rated from measured curvature, road width and elevation change.
* Each car profile adjusts top speed, acceleration, braking, steering, grip, weight and
  drift response through the shared physics model. AI drivers use different car profiles;
  AI difficulty controls their behavior and racecraft.
* Track Select shows layout, type, star difficulty, measured length and local best times.
  The Garage previews each procedural car with a slow rotation.
* Cars start on the grid (you start 3rd when the field is large enough) and a
  3 - 2 - 1 - GO countdown runs.
* Each track has 12 checkpoints. A lap only counts after the checkpoints were passed **in
  order**, so cutting across the grass or driving backwards over the line gives no lap.
* The HUD shows lap, position, speed and race time. A mini-map shows every racer.
* Race results appear after all cars finish and include final positions, race/lap times,
  selected race settings and local best times. Choose **Race Again**, **Change Setup** or
  **Main Menu**.

## Settings

Main menu -> Settings: music volume, sound-effects volume, graphics quality, and visual
weather. Low uses no shadow maps, 64px generated textures and reduced scenery/effects;
Medium uses 1024px shadow maps and balanced detail; High uses 2048px shadow maps, tighter
shadow coverage, antialiasing and full scenery/effects. Texture anisotropy, clouds, rocks,
landscape props and particle limits are controlled by the same quality presets.
Choose Day, Sunset, Night or Rain atmosphere. Rain adds visual tire spray and does not alter
driving physics. These options are saved in `data/settings.json`. Race completion totals and
best race/lap times are saved in `data/progression.json`. If the game runs slowly, set
quality to **Low**.

Game logic (`game/track`, `physics`, `collision`, `checkpoint`, `ai`, `race`) does not import

## Visual asset replacements

All scenes remain playable without optional visual files; the game uses generated procedural
defaults. Add higher-resolution texture replacements to `assets/textures/`: `road.png`,
`grass.png`, `dirt.png` or coastal `water.png`, or quality-specific variants such as
`road_high.png` and `grass_low.png`. A quality-specific texture takes precedence over its
generic counterpart.
The `assets/materials/`, `assets/skyboxes/`, `assets/particles/` and `assets/audio/` folders
are reserved for future local visual/audio content.

Existing optional sound and texture paths (relative to the project):

| File | What it does |
| --- | --- |
| `assets/sounds/engine.wav` (or .ogg/.mp3) | looping engine sound (pitch follows speed) |
| `assets/sounds/tire.wav` | looping tire squeal |
| `assets/sounds/crash.wav` | collision |
| `assets/sounds/beep.wav`, `go.wav` | countdown |
| `assets/sounds/finish.wav` | race finish |
| `assets/sounds/music.wav` (or .ogg/.mp3) | background music loop |
| `assets/textures/road.png`, `grass.png`, `dirt.png` | tiling textures replacing generated defaults |
| `assets/fonts/ui.ttf` | UI font (otherwise Segoe UI / Arial from Windows is used) |

Use the same file names to replace a sound. Delete a generated `.wav` to have it recreated.
Missing or broken optional files never stop the game; the generated defaults are used.
The `assets/models/`, `assets/cars/` and `assets/tracks/` folders are reserved for your own
assets.

## Troubleshooting

* **`Panda3D is not installed`** - run `pip install -r requirements.txt` in the active Python.
* **`pip` cannot find panda3d** - check `python --version` (64-bit, 3.9 or newer) and update pip:
  `python -m pip install --upgrade pip`.
* **Low FPS** - Settings -> Graphics quality: Low. Update your graphics driver.
* **No sound** - check the Windows default playback device and the volume sliders in Settings.
  If audio cannot start, the game still runs silently.
* **Black window / crash on start** - update your graphics driver; the error is saved to
  `data/error.log`.
* **Settings broken** - delete `data/settings.json`; defaults are used.
