# Iron Dominion

A 2D isometric Real-Time Strategy game built with Python + Pygame.

**Current status: Phase 1 — Project Foundation & Isometric World.**

## Requirements

* Python 3.10+
* pygame-ce 2.5.3+

## Install

```bash
python -m pip install -r requirements.txt
```

The project uses pygame-ce, a drop-in Pygame-compatible distribution with
prebuilt wheels for newer Python versions on Windows. Do not install both
`pygame` and `pygame-ce` in the same environment; they provide the same
`pygame` import package.
